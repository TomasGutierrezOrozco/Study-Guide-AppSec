# Ejercicios SAST

Esta carpeta separa la practica de revision estatica del resto del material.

## Contenido

- `soluciones/ejercicios_resueltos.md`: ejercicios comentados con hallazgo, impacto y remediacion.
- `snippets/`: archivos pequenos por lenguaje para practicar identificacion de vulnerabilidades.

## Recomendacion de uso

1. Abre primero un snippet sin mirar la solucion.
2. Identifica fuente, sink, validaciones y explotabilidad.
3. Redacta mentalmente el hallazgo en 3 partes: evidencia, impacto y recomendacion.
4. Contrasta con `soluciones/ejercicios_resueltos.md`.
